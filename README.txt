## 📋 Описание

Лабораторная работа посвящена изучению основных библиотек Python для машинного обучения
(NumPy, Pandas, Matplotlib, SciPy, scikit-learn, TensorFlow, Keras, PyTorch) и получению
практических навыков работы с табличными данными: чтение/запись, предобработка,
статистический анализ, тензорные вычисления, обработка изображений.

---

## 🎯 Цель работы

Изучить основные библиотеки Python для машинного обучения и приобрести практические
навыки работы с табличными данными.

## ✅ Задачи

1. Освоить чтение и запись данных в различных форматах.
2. Научиться выявлять и обрабатывать проблемы в данных.
3. Реализовать собственные функции масштабирования и сравнить их со `sklearn`.
4. Освоить статистический анализ данных средствами NumPy, Pandas, SciPy.
5. Научиться работать с тензорами TensorFlow, PyTorch, Keras.
6. Освоить базовую обработку изображений средствами SciPy.

---

## 🛠 Требования

- **Python** 3.10–3.11
- Знание основ Python (синтаксис, функции, классы, модули)
- Понимание базовой линейной алгебры и статистики
- Навыки работы в командной строке
