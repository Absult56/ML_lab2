# Лабораторная работа №2: Обучение без учителя

Реализация алгоритмов понижения размерности, кластеризации и поиска аномалий на языке Python с использованием библиотеки `scikit-learn` (Вариант 12).

---

## 📌 Цель работы
Проанализировать многомерные числовые данные для Варианта 12, выполнить отбор признаков методами понижения размерности (PCA, SVD, ICA), выявить шумовые компоненты, провести сравнительный анализ 12 алгоритмов кластеризации и обнаружить аномальные значения (выбросы)[cite: 12, 14, 15].

---

🔬 Реализованный функционал
Часть 1. Понижение размерности и отбор признаков
Расчет матрицы парных корреляций (sns.heatmap).

Построение матрицы разброса признаков (pd.plotting.scatter_matrix).

Оценка значимости компонент тремя методами:

PCA (Principal Component Analysis) — по доле объясненной дисперсии.

SVD (Singular Value Decomposition) — по сингулярным числам/дисперсии.

ICA (FastICA) — по нормализованному абсолютному значению куртозиса (эксцесса).

Построение двумерных проекций Biplot с отображением направлений и длин векторов исходных признаков.

Часть 2. Кластеризация и обнаружение аномалий
Определение оптимального числа кластеров с помощью метода локтя (KMeans inertia).

Сравнительное тестирование 12 алгоритмов кластеризации на общей сетке 3x4:

K-Means

Affinity Propagation

Mean-Shift

Spectral Clustering

Ward Hierarchical Clustering

Agglomerative Clustering

DBSCAN

HDBSCAN

OPTICS

Gaussian Mixtures (GMM)

BIRCH

Bisecting K-Means

Расчет коэффициента силуэта (silhouette_score) для оценки качества разбиения.

Локализация и визуализация аномалий (выбросов) плотностным методом DBSCAN.

📊 Основные выводы по Варианту 12
Отбор признаков: Корреляционный анализ показал отсутствие строгих линейных зависимостей между признаками (|r| <= 0.10). Дисперсия распределена относительно равномерно по всем 5 компонентам (от 24% до 17%). Явных шумовых признаков с околонулевой информативностью нет, наименьший вклад вносит 5-я компонента.

Структура кластеров: Анализ метода локтя показал оптимум на значениях k = 3 и k = 4.

Обнаружение аномалий: Алгоритм DBSCAN с параметрами eps = 0.35 и min_samples = 6 выделил целостное плотное центральное ядро данных и изолировал разреженный шум по внешним границам.

Лучший алгоритм: Методы на основе плотности (DBSCAN, HDBSCAN) наиболее объективно отражают топологию данных Варианта 12, так как не навязывают искусственных сферических границ. Для задач строгой параметрической сегментации пространства оптимален Gaussian Mixture (GMM) с k = 3.
